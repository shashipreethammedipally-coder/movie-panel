# MovieHub - TMDB React Movie Panel

## Features

- Popular Movies page
- Top Rated Movies page
- Upcoming Movies page
- Single Movie Details page
- Movie cast section
- Global movie search
- Search results page
- Pagination
- Responsive design
- Reusable React components
- TMDB API integration

## Run locally

1. Install dependencies:
   npm install

2. Create `.env` in the project root:

   VITE_TMDB_API_KEY=YOUR_TMDB_API_KEY

3. Start the project:

   npm run dev

## CodeSandbox

Create a React/Vite Sandbox, upload/import these project files, add `VITE_TMDB_API_KEY` under the Sandbox environment variables, then run the project.

Do not publish your private TMDB API key in a public repository.
